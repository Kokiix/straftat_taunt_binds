# Taunt Binds

A simple mod to allow rebinding taunts, littewaly a ~~1 line patch~~ 1 function transpiler. Also includes the feature of [Infinite Taunt](https://thunderstore.io/c/straftat/p/Dimolade/Infinite_Taunt/) for optionally removing taunt cooldown.

In a rare case of the source code being competent, vanilla clients are protected from taunt spam. Your own limiter can be disabled in the config.
